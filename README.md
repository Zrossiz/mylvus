# Mylvus

## Описание проекта
Проект представляет собой векторную базу данных, которая хранит слова и их вектора. Есть возможность поиска схожих векторов 

## Требования к проекту
- Хранить слова и их эмбединги.  
- Конвертация слова в эмбединг.  
- Поиск похожих слов.  
- Возможность получать похожие слова с определенным порогом схожести.  
- База данных должна работать с разными форматами файлов
