# Mylvus

## Описание проекта
Проект представляет собой векторную базу данных, которая хранит слова и их вектора. Есть возможность поиска схожих векторов 

## Что уммет база данных
- Хранение эмбеддингов
- Поиск через косинусное расстояние
- Поиск через Евклидово просстранство
- Создание эмбеддингов

## Производительность
Я иду итеративно. Первая итерация была с чтением всех векторов в память на каждый запрос и хранение в json формате.
Вторая итерация - хранение в памяти всех векторов со старта приложения и бинарный формат хранения данных
