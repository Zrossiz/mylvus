Баги  

[x]  Повторное создание коллекции уничтожает её файл.
os.Create обнуляет существующий файл до проверки уникальности коллекции в SQLite. Запрос завершается ошибкой, но векторы уже потеряны.

[x] Нет проверки размерности перед записью вектора.
Слишком длинный вектор при использовании свободного слота перезапишет соседний. Слишком короткий оставит часть старых данных либо приведёт к ошибке чтения.

[x] Удаление может объявить занятый слот свободным.
Delete принимает id int64, хотя идентификаторы эмбеддингов — UUID. Не проверяется, была ли запись действительно удалена; переданный offset всё равно добавляется в свободные. Следующая вставка может перезаписать действующий вектор. Удаление метаданных и освобождение слота также не объединены SQL-транзакцией.

[x] Уникальность offsets не учитывает коллекцию.
В разных файлах допустим одинаковый offset, включая 0. Текущие ограничения embeddings_meta и free_offsets запрещают это. После исправления ограничений нужно исправить и GetFreeOffset: его внешний DELETE не ограничен коллекцией.

[x] Кеш изменяется под RLock.
Несколько запросов могут одновременно писать в map при загрузке коллекций. Возможны гонка данных и аварийное завершение процесса. GetAllFromDisk также меняет кеш без собственной блокировки — нужно учитывать все пути его вызова.

[x] Первый поиск после перезапуска возвращает пустой результат.
GetAll загружает данные с диска, но возвращает прежнее пустое значение embs, а не загруженные данные.

[ ] Ошибки между этапами вставки оставляют несогласованное состояние.
Свободный offset удаляется до записи; при ошибке он теряется. Если файл записан, а метаданные нет — остаётся неучтённый вектор. Если обновление кеша падает после сохранения метаданных, клиент получает ошибку для уже сохранённой записи и может повторить её.

[x] Название коллекции используется как часть пути без проверки.
Значения с ../ позволяют выйти за пределы каталога коллекций. В сочетании с os.Create это может обнулить другой доступный приложению файл с расширением .dat.
